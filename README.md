# GH 학교 설문 — 설정 가이드

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 앱 전체 (로그인, 내 정보, 설문 목록·만들기·참여·결과) |
| manifest.json, service-worker.js, icon-*.png | 폰에 앱처럼 설치되게 해주는 파일 |
| firestore.rules | 데이터 보안 규칙 (파이어베이스 콘솔에 붙여넣기) |

모든 파일을 GitHub 저장소(`Pb`)의 같은 폴더에 올리면 돼요. 기존 index.html은 이 파일로 교체하세요.

## 1. 체험 모드로 먼저 확인
설정 없이 올리면 **체험 모드**로 동작해요. 아무 번호나 입력하고 인증번호 `123456`을 넣으면 로그인돼요.
체험 모드 데이터는 그 기기(브라우저)에만 저장돼서, 다른 사람과 설문을 공유하려면 아래 파이어베이스 설정이 필요해요.

## 2. 파이어베이스 프로젝트 만들기
1. https://console.firebase.google.com 접속 → **프로젝트 추가**
2. 프로젝트 홈에서 웹 아이콘 `</>` 클릭 → 앱 이름 입력 → 등록

## 3. 설정값 붙여넣기
등록하면 나오는 `firebaseConfig = { ... }` 안의 값을 복사해서
index.html 맨 아래쪽 스크립트의 `const firebaseConfig = { ... }` 부분에 붙여넣어요.

## 4. 전화번호 로그인 켜기
1. **Authentication → 시작하기 → Sign-in method → 전화** 사용 설정
2. **Authentication → 설정 → 승인된 도메인**에 `filldo-2217.github.io` 추가
3. 실제 문자를 보내려면 프로젝트를 **Blaze(종량제) 요금제**로 바꿔야 해요. 하루 10건까지는 무료이고, 그 이상은 문자당 요금이 나와요.
   → Google Cloud 콘솔의 **예산 알림**을 꼭 설정해두세요.
4. 개발 중에는 **Sign-in method → 전화 → 테스트용 전화번호**에 번호와 인증번호를 등록하면 문자 없이 테스트할 수 있어요.

## 5. 데이터베이스 만들기
1. **Firestore Database → 데이터베이스 만들기** → 위치는 `asia-northeast3 (서울)` → 프로덕션 모드
2. **규칙** 탭에 `firestore.rules` 내용을 전부 붙여넣고 **게시**

## 바꿀 수 있는 설정
- 반 개수: index.html의 `MAX_CLASS = 12`
- 사이트를 수정해서 다시 올릴 때: service-worker.js의 `survey-v2` 숫자 올리기

## 저장되는 정보
- `users/{uid}`: 전화번호, 학년, 반, 성별 — 본인만 볼 수 있음
- `surveys/{id}`: 설문 제목, 설명, 대상 학년, 마감일, 질문
- `surveys/{id}/responses/{uid}`: 답변 + 학년·반·성별 — 설문 만든 사람만 볼 수 있음 (전화번호는 포함되지 않음)
